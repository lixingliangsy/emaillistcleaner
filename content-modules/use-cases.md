# ListClean — Use Cases

## Persona 1 — Newsletter operator
**Pain:** A growing list slowly fills with role accounts and throwaway addresses that hurt open rates.
**How:** Paste the export, get a cleaning report, drop the flagged rows, re-import. Repeat before each send.

## Persona 2 — Agency / freelance marketer
**Pain:** Client lists arrive messy from events and lead forms; manual cleaning eats billable hours.
**How:** Run each client list through ListClean, hand back a deliverability score + clean export as part of the retainer.

## Persona 3 — Solo founder doing cold outreach
**Pain:** One bad send can sink a brand-new domain's reputation.
**How:** Verify a prospect list before the first touch; keep only reachable, human inboxes.

## Vertical notes
- E-commerce: clean post-purchase signups before a win-back.
- SaaS: scrub trial signups to protect onboarding email deliverability.
