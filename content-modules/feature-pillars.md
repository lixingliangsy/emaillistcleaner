# ListClean — Feature pillars

## Core engine
- Flags invalid syntax, role-based (info@, admin@), and disposable addresses
- Deliverability score for the pasted list
- Copy-paste-ready clean list

## Workflow & output
- Marketers and founders protect sender reputation before the next send
- Drop risky addresses; keep the good ones
- Fast hygiene without a full ESP login

## Trust & control
- Decision-support for list hygiene — not a deliverability guarantee
- No fabricated inbox-placement percentages
- Demo mode without a live API key
